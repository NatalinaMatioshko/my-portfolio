# Nataliia Matyoshko — Portfolio

Modern multilingual portfolio built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Roles

1. **Primary:** English Trainer & Language Educator
2. **Secondary:** Frontend / Full-Stack Developer (EdTech)

## Features

- Single-page sections: Hero, About, Experience & EdTech, Projects, Skills, Certificates, Contact
- Language switcher: EN / UK / IT
- Light / dark theme toggle
- Smooth Framer Motion animations

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
